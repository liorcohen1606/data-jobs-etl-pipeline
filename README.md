# Tech Jobs ETL Pipeline

## Project Overview
This project is an automated ETL (Extract, Transform, Load) pipeline designed to fetch, clean, and store tech job opportunities.

## Tech Stack
*   **Language:** Python
*   **Libraries:** Requests, Pandas
*   **Database:** SQLite
*   **Version Control:** Git & GitHub

## How it works
1.  **Extract:** Fetching real job data from a public Job Board API.
2.  **Transform:** Cleaning data, filtering relevant columns, and standardizing text using Pandas.
3.  **Load:** Storing the processed data into a local SQLite database for future analysis.
